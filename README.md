# Drip Zine
Coffee-shop hand-drip recipes, scaled to your beans, with a pour timer that talks. English first, Japanese toggle.
Static site: `index.html` + `app.js` + `brew.js` + `data.js`. Data regenerated by `tools_gen.py` from the baristai.net catalog (recipe credit belongs to each shop/barista).
`node check.mjs` runs the math self-check. `?motif=a|b|c` switches the look (Little Amps / Escape / Redbrick).
